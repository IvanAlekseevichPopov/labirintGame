# Один модуль примитивов рисования

Контекст рисования передаётся по-разному: `art.js` через `useContext`, а `props.js`, `rockets.js`, `sky.js`, `finale.js`, `profiles.js` — через свой модульный `c`. Мелкие хелперы (`disc`, `poly`, `bar`, `line`…) повторяются по модулям. Просится один модуль примитивов вида `(g, …)`.
