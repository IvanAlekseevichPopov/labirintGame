# Ночь на Марсе и Европе

Ночные уровни есть только на Луне. Пресеты фар для Марса и Европы уже заготовлены в `HEADLIGHTS` (`headlights.js`), уровней нет.

- Мелодия для ночи на этих планетах не выбрана: сейчас `songFor()` даёт `moonNight` любой ночи.
- Парсер не пускает показ `intro` на ночной уровень.
