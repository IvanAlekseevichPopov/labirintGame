# Лабиринт

Браузерная игра-лабиринт для ребёнка 6 лет: ровер едет по лабиринту к ракете на Луне, Марсе и Европе. Запускается на ноутбуке в Chrome, картинка идёт на ТВ по HDMI, управление геймпадом или клавиатурой.

## Принципы игры
- Проиграть нельзя: нет врагов, таймеров и game over. Ребёнок очень не любит проигрывать.
- Текст на экране: только простые слова, крупно. Всё должно читаться с дивана.
- Уровни захардкожены, чтобы ребёнок их узнавал. Родитель отбирает их руками.

## Запуск
- Нужен http-сервер, потому что игра на ES-модулях: `python3 tools/dev-server.py` (порт 8123, конфиг в `.claude/launch.json`). Он отключает кеш: обычный `python3 -m http.server` даёт Chrome держать старые модули после правок. Целевой хостинг — GitHub Pages, поэтому все пути относительные.
- При загрузке показывается стартовый экран. Enter, пробел или клик запускают игру со звуком. Кнопка или крестовина геймпада тоже запускают, но без звука: Chrome не считает геймпад жестом пользователя, поэтому в углу висит иконка «звук выкл», пока не нажмут клавишу.
- `#level=N` или `?level=N` открывает уровень N. Игра сама держит `#level` актуальным, поэтому рефреш продолжает с того же уровня.
- Управление: стрелки, Esc — пауза, R — рестарт уровня, M — вкл/выкл музыку. Геймпад: крестовина, Start (кнопка 9) — пауза; Select (8) в игре ничего не делает, чтобы ребёнок не сбросил уровень случайно. В меню паузы: продолжить, начать уровень заново, звук вкл/выкл (глушит всё). Переключатели звука и музыки запоминаются в браузере.

## Файлы
- `index.html` — только canvas и `js/main.js`.
- `js/main.js` — запуск: загрузка и проверка уровней, сцены (title → playing ⇄ paused → finale, error), игровое время (стоит на паузе), маршрутизация ввода в текущую сцену, игровой цикл, `#level`.
- `js/game.js` — правила игры без DOM: состояние, ввод (press/release), движение, фазы победы. Время и размер клетки получает параметрами. `update()` возвращает события: `levelStart`, `move`, `bump`, `landmark`, `stop`, `arrive`, `ignite`, `liftoff`; к ним цепляется звук.
- `js/input.js` — клавиатура, мышь и геймпад, превращаются в действия (`dir`, `confirm`, `restart`, `gesture`, `blur`), которые `main.js` направляет в текущую сцену.
- `js/render.js` — раскладка, слои лабиринта и следов, кадр. `js/art.js` — роверы, ориентиры, ракета, текст.
- `js/audio.js` — звук в стиле NES на Web Audio: эффекты, гул мотора у каждого ровера, музыка. До нажатия клавиши или клика молчит. Громкости — `VOLUME` в начале файла. `js/music.js` — мелодии планет и джинглы нотами (формат описан в шапке файла), темп — `bpm`. Послушать всё: `tools/sound-test.html`.
- `js/config.js` — константы. `js/planets.js` — палитры планет. `js/random.js` — seeded PRNG.
- `level-format.js` — парсер и формат уровней, общий для игры, генератора и тестов.
- `levels.js` — 40 уровней в ASCII. Источник правды, правится руками.
- `tools/gen-levels.mjs` — генератор уровней, в игре не используется. `tools/gamepad-test.html` — показывает оси и кнопки геймпада.
- `tests/` — `npm test` (node --test, без зависимостей).

## Формат уровня
Клетки стоят на нечётных строках и столбцах, символы между ними — стены. Рамка целиком из `#`. Обозначения: `S` старт, `R` ракета (ровно по одной), `F` флаг, `A` антенна, `C` большой кратер (на Европе — полынья); только латиница. Планета задаётся полем `planet`: `moon` | `mars` | `europa`. Ошибку в уровне парсер показывает прямо на экране игры, с номером строки.

## Деплой
GitHub Pages через `.github/workflows/pages.yml` на каждый пуш в `main`: прогоняет тесты, собирает сайт в `site/` и проставляет `?v=<sha>` во все ссылки на модули (`tools/stamp-version.mjs`). Без версии браузер после деплоя может смешать старые и новые модули из кеша. В репозитории ссылки остаются без версии.

## Генератор
- `node tools/gen-levels.mjs --only 4,26` — перегенерировать только эти уровни, остальные не трогать. Чтобы получить другой лабиринт для уровня, увеличь его номер в `VARIANTS`.
- `--force` — перегенерировать весь набор. Затирает ручные правки.
- Каждый уровень — лучший из 300 кандидатов по кривой сложности: длина пути, «наивное» прохождение, ловушки, path/manhattan. Генератор печатает таблицу метрик.

## Геймпад
Дешёвый «Twin USB Joystick» (0810:0001): mapping `""`, крестовина приходит осями a0/a1. После переподключения приёмника Chrome на macOS теряет геймпад, помогает только полный перезапуск Chrome (Cmd+Q).
